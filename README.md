# 📊 E-Commerce Sales & Customer Analytics

## 🚀 Project Overview
This project focuses on analyzing an online retail dataset to uncover sales trends and perform customer segmentation using RFM analysis.

## 📂 Dataset
Online Retail Dataset (UCI Machine Learning Repository)

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔹 Steps Performed
- Data Cleaning & Preprocessing
- Handling Missing Values
- Removing Cancelled Orders
- Feature Engineering
- Exploratory Data Analysis (EDA)
- RFM Customer Segmentation

## 📈 Key Insights
- Identified top-performing countries and products
- Analyzed monthly sales trends
- Segmented customers into high-value groups

## 🎯 Outcome
Generated business insights to improve customer retention and sales strategy.
